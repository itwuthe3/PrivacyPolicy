# ハビットコンパス プライバシーポリシー

最終更新日: 2026年7月28日

ハビットコンパス（以下「本アプリ」）は、毎週の計画と振り返りのためのプランナーアプリです。
本ポリシーは、本アプリが取り扱う情報とその利用目的を説明します。

## 記録はすべて端末内に保存されます

本アプリでお客様が入力する情報 — ミッション・役割・長期目標・週の「大きな石」・タスク・
日々や週の振り返り・信頼残高の記録など — は、**すべてお使いの端末内にのみ保存されます**。

- アカウント登録は不要です。ユーザー登録もログインもありません
- 本アプリは記録の送信先となるサーバーを持ちません。開発者がお客様の記録を
  収集・閲覧・送信することは一切ありません
- 記録はアプリを削除すると端末から消えます

## カレンダーへのアクセス

タスクを予定としてカレンダーに登録・更新する機能のために、カレンダーへのアクセス許可
（フルアクセス）を求めることがあります。

- **利用目的**: 本アプリが作成した予定の登録・更新・削除のみに使用します
- **読み取りについて**: フルアクセスの許可が必要なのは、一度登録した予定を後から
  更新・削除するためです。既存の予定の内容を読み取って外部へ送信することはありません
- **同期先**: 登録先はiOSの「カレンダー」です。Google カレンダーやOutlookなどに
  反映されるのは、それらをiOSのアカウントとして設定している場合に、iOS側の機能で
  同期されるためです。本アプリがこれらのサービスへ直接接続することはありません
- **任意です**: 許可しなくても、カレンダー連携以外のすべての機能をご利用いただけます

## 通知

計画や振り返りのリマインドのために、通知の許可を求めることがあります。
通知はすべて端末内で生成される**ローカル通知**で、外部サーバーは使用しません。
設定画面からいつでも個別にオフにできます。

## Face ID / Touch ID（アプリロック）

記録は内心のメモにあたるため、任意でアプリロックをかけられます。

- 認証にはiOS標準の仕組み（LocalAuthentication）を使用します
- **生体情報そのものは端末のSecure Enclaveで管理され、本アプリが受け取ることはありません**。
  本アプリが受け取るのは認証の成否のみです
- アプリロックは既定でオフです

## データの書き出し

設定画面から、記録をMarkdown形式のテキストとして書き出せます。書き出したデータの
送信先はお客様が選んだ共有先（メール、ファイルアプリなど）であり、本アプリが
自動的にどこかへ送信することはありません。

## 収集しない情報

本アプリは、以下を**一切行いません**。

- 広告の表示（広告SDKを含みません）
- 利用状況の分析・アクセス解析（AnalyticsやクラッシュレポートのSDKを含みません）
- 広告識別子（IDFA）の利用、およびApp Tracking Transparencyによるトラッキング
- 第三者へのデータ提供・販売

## 第三者サービス

本アプリは、第三者が提供するSDKやサービスを一切組み込んでいません。

## お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。

本ポリシーを変更する場合は、本ページで告知します。

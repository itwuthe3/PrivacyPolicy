# TAMALIBA プライバシーポリシー

最終更新日: 2026年8月25日

TAMALIBA（以下「本アプリ」）は、メモ・やること・あとで読むものをひとつのタイムラインに
まとめるアプリです。本ポリシーは、本アプリが取り扱う情報とその利用目的を説明します。

## 記録はすべて端末内に保存されます

本アプリでお客様が入力する情報 — 投稿の本文・コメント・タグ・やることの完了状態・
保存（ブックマーク）・リマインドの日時など — は、**すべてお使いの端末内にのみ保存されます**。

- アカウント登録は不要です。ユーザー登録もログインもありません
- 本アプリは記録の送信先となるサーバーを持ちません。開発者がお客様の記録を
  収集・閲覧・送信することは一切ありません
- インターネットに接続していなくても、すべての機能をご利用いただけます
- 記録はアプリを削除すると端末から消えます

## Apple Watch との連携

Apple Watch で入力したメモは、iPhone へ届けるために **Apple Watch と iPhone の間でのみ**
やり取りされます。

- 通信には iOS / watchOS 標準の仕組み（WatchConnectivity）を使用します。この通信は
  ペアリングされたお客様の端末同士で完結し、開発者や第三者のサーバーを経由しません
- iPhone と接続していないときは、メモは Apple Watch 内に保存され、次に接続したときに
  iPhone へ送られます

## 共有シート（他のアプリからの保存）

Safari や他のアプリの共有シートから、記事の URL やテキストを本アプリに保存できます。
受け取った内容は端末内の同じ保存先に書き込まれるだけで、外部へ送信されることはありません。

## 通知

投稿ごとのリマインドのために、通知の許可を求めることがあります。
通知はすべて端末内で生成される**ローカル通知**で、外部サーバーは使用しません。
許可しなくても、リマインド以外のすべての機能をご利用いただけます。

## Siri・ショートカット・ウィジェット

「TAMALIBA にメモ」などの音声操作、ショートカット、ホーム画面や文字盤のウィジェットに
対応しています。これらの機能で扱う内容も端末内で完結し、外部へ送信されることはありません。

音声認識は Apple が提供する OS 標準の機能によって行われます。その取り扱いについては
Apple のプライバシーポリシーをご確認ください。

## Spotlight 検索

過去の投稿を iPhone の Spotlight 検索から見つけられるよう、投稿の内容を端末内の
検索インデックスに登録します。このインデックスは端末内にあり、外部へ送信されません。

## データの書き出し

設定画面から、記録を JSON または Markdown 形式で書き出せます。書き出したデータの
送信先はお客様が選んだ共有先（メール、ファイルアプリなど）であり、本アプリが
自動的にどこかへ送信することはありません。

## iCloud バックアップ

端末の iCloud バックアップを有効にしている場合、本アプリのデータもバックアップの
対象に含まれます。これは iOS の標準機能によるもので、バックアップは
お客様の iCloud アカウントで管理されます。開発者がその内容を閲覧することはできません。

## 収集しない情報

本アプリは、以下を**一切行いません**。

- 広告の表示（広告SDKを含みません）
- 利用状況の分析・アクセス解析（AnalyticsやクラッシュレポートのSDKを含みません）
- 広告識別子（IDFA）の利用、およびApp Tracking Transparencyによるトラッキング
- 第三者へのデータ提供・販売

## 第三者サービス

本アプリは、第三者が提供するSDKやサービスを一切組み込んでいません。

## お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。

本ポリシーを変更する場合は、本ページで告知します。

# TAMALIBA サポート

TAMALIBA は、メモ・やること・あとで読む記事を、チャットに書き込む感覚でひとつの
タイムラインに集めるアプリです。記録はすべて端末内に保存され、広告もトラッキングもありません。

## よくある質問

### 使いはじめ

**Q. どう使いはじめればいいですか？**
アプリを開くと、下に入力欄があります。思いついたことを書いて送信すれば、それだけで
タイムラインに積み上がります。フォルダ分けもページ作成も必要ありません。
分類したくなったら、あとからタグを付けてください。

**Q. メモ・タスク・ブックマークの種類を選ぶ必要はありますか？**
ありません。TAMALIBA は投稿に種類を持たせない設計です。すべてはまず「投稿」として書き、
やることにしたいものだけ、あとからワンタップで TODO に切り替えます。
分類はタグで自由に行ってください。

**Q. アカウント登録は必要ですか？**
不要です。ログイン画面はありません。データはすべてお使いの端末内に保存されます。

### 書く・整える

**Q. 太字や箇条書きはどうやって入力しますか？**
入力欄の左にある「Aa」ボタンで書式ツールバーを開きます。太字・斜体・打ち消し線・
インラインコード・リンク・箇条書き・番号付きリスト・チェックリスト・引用・コードブロックを
選べます。記号を覚える必要はありません。

**Q. 箇条書きを終わりたいときは？**
空の項目のまま改行すると、箇条書きが解除されて通常の行に戻ります。

**Q. 投稿を書き直せますか？**
できます。投稿をタップして詳細画面を開き、本文を編集してください。

**Q. コメントは何に使いますか？**
ひとつの投稿に対する追記や経過の記録に使えます。コメント自体も、投稿と同じように
TODO にしたり、保存したり、リマインドを設定したりできます。

### やること・リマインド

**Q. メモをやることに変えるには？**
タイムラインで投稿を長押しするか、詳細画面のメニューから「TODO にする」を選びます。
完了したらチェックを付けてください。

**Q. リマインドは通知されますか？**
投稿ごとに日時を設定すると、その時刻に通知が届きます。通知は端末内で生成されるもので、
外部のサーバーは使いません。届かない場合は、iOS の「設定」＞「通知」＞ TAMALIBA で
通知が許可されているかご確認ください。

**Q. ホーム画面のウィジェットは何ができますか？**
未完了のやることが表示され、その場でタップして完了にできます。何もない場所をタップすると、
アプリの入力画面が開きます。

### アプリを開かずに集める

**Q. Safari で見ている記事を保存するには？**
共有ボタンから TAMALIBA を選んでください。開いた画面でひとこと添えたり、
タグを付けたりしてから保存できます。共有シートに出てこない場合は、
共有シートの一番下にある「その他」から TAMALIBA を有効にしてください。

**Q. Siri から投稿できますか？**
できます。「TAMALIBA にメモ」「TAMALIBA に保存」「TAMALIBA に追加」などと話しかけてください。
ショートカットアプリからも呼び出せます。

**Q. Apple Watch だけでメモできますか？**
できます。Watch アプリの「メモする」から、音声入力・キーボード・スクリブルで入力してください。
iPhone が近くになくても Watch 内に保存され、次に iPhone と接続したときに自動で送られます。
送信待ちの件数は Watch のホーム画面に表示されます。

**Q. 文字盤からすぐ開けますか？**
文字盤の編集からコンプリケーションに TAMALIBA を追加すると、ワンタップで入力画面が開きます。

### 探す

**Q. 過去の投稿はどうやって探しますか？**
画面上部の検索から、本文・タグ・コメントを横断して検索できます。
ツールバーのフィルタからは、TODO・完了済み・保存済み・リマインドあり・タグ別で絞り込めます。

**Q. iPhone の標準の検索からも探せますか？**
探せます。ホーム画面を下にスワイプして表示される Spotlight 検索に投稿の内容が出てきます。
タップするとその投稿が開きます。

### データ

**Q. 記録を他の端末と同期できますか？**
現在は端末内保存のみで、端末間の同期には対応していません。今後の検討課題としています。

**Q. データのバックアップはどうすればいいですか？**
設定画面から、すべての記録を JSON または Markdown で書き出せます。
JSON はデータの保管用、Markdown は人が読む用です。
端末の iCloud バックアップを有効にしている場合は、そちらにも含まれます。

**Q. 機種変更するときは？**
iCloud やパソコン経由で端末のバックアップから復元すると、データも引き継がれます。
念のため、設定画面から JSON で書き出しておくことをおすすめします。

**Q. アプリを削除するとどうなりますか？**
端末内に保存されたデータも一緒に削除され、元に戻せません。
削除する前に、設定画面からデータを書き出してください。

**Q. 共有シートやウィジェットから保存したのに、アプリに出てきません**
アプリが起動したままだと、すぐには反映されないことがあります。
アプリを一度終了してから開き直してください。

**プライバシーポリシー**

このプライバシーポリシーは、Takahiro Ito（以下「サービス提供者」）が作成した「タイドテーブル」アプリケーション（以下「本アプリ」）に適用されます。本サービスは「現状のまま改変せず」使用することを意図しています。

**収集する情報**

**本アプリは、いかなる個人情報も収集・保存・送信しません。**

本アプリはサーバーと通信しません。潮位はアプリに同梱した調和定数から端末内で計算しており、外部への問い合わせを一切行いません。したがって、以下のいずれも行っていません。

* 利用状況の記録・送信（アクセス日時、利用時間、操作履歴など）
* 端末情報の収集（IPアドレス、OSバージョン、端末識別子など）
* クラッシュログや分析データの外部送信
* 広告の配信および広告識別子（IDFA）の利用

**位置情報の取り扱い**

本アプリは、お客様が許可した場合にのみ、端末の位置情報を利用します。

* 用途は「現在地から最も近い潮汐の地点を選ぶ」ことだけです
* 位置情報は端末内での計算にのみ使用され、**外部に送信されることはありません**
* 保存もしません。取得した座標は最寄り地点を求めた後に破棄されます
* 位置情報の利用を許可しなくても、地点を手動で選ぶことで本アプリのすべての機能をお使いいただけます

**アプリ内に保存される情報**

以下の設定は、お客様の端末内にのみ保存されます。外部に送信されることはありません。

* 選択中の地点、お気に入りの地点
* 通知の設定（通知する潮回り、タイミング、通知する日）
* 表示の設定

iPhone と Apple Watch の両方に本アプリをインストールしている場合、選択中の地点とお気に入りは Apple の WatchConnectivity を用いて端末間で同期されます。この通信は Apple の仕組みによりお客様の端末間で直接行われ、サービス提供者を含む第三者のサーバーを経由しません。

**第三者のアクセス**

**本アプリは第三者のサービス（分析、広告、クラッシュレポートなど）を一切利用していません。** 第三者に提供するデータもありません。

**アプリ内課金について**

本アプリには「開発者を応援」という任意のアプリ内課金があります。購入しても機能は変わりません（すべての機能は購入の有無にかかわらず最初からご利用いただけます）。決済は Apple が処理し、サービス提供者がお客様の氏名・クレジットカード番号などの決済情報を受け取ることはありません。

**データの出典**

潮位の計算に用いる調和定数は、気象庁が公開する潮位表の推算値から推定したものです。

* 出典: 気象庁 潮位表 https://www.data.jma.go.jp/kaiyou/db/tide/suisan/

**免責事項**

本アプリが表示する潮位は天文潮のみを計算したもので、気圧や風による気象潮は含みません。実際の潮位は数十cm異なることがあります。**航海の用に供するものではありません。**

**お子様のプライバシー**

本アプリは個人情報を一切収集しないため、13歳未満のお子様を含むすべての方に安全にご利用いただけます。

**オプトアウトの権利**

本アプリは情報を収集していませんが、端末内の設定を削除したい場合は、本アプリをアンインストールしてください。保存されていた設定はすべて削除されます。

**変更**

このプライバシーポリシーは、理由の如何を問わず随時更新される場合があります。サービス提供者は、新しいプライバシーポリシーでこのページを更新することにより、プライバシーポリシーの変更をお知らせします。変更を定期的に確認することをお勧めします。継続的な使用は、すべての変更の承認とみなされます。

**お客様の同意**

本アプリを使用することにより、お客様は、このプライバシーポリシーに定められた通り、現在および将来の改訂版に従って、お客様の情報の取り扱いに同意したものとみなされます。

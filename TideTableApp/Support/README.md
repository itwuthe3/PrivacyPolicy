# タイドテーブル 潮見表・タイドグラフ・潮回り　サポートページ

## アプリ概要

広告なし・閲覧期間の制限なし・完全オフラインの潮汐表アプリです。Apple Watch 単体でも動きます。

### 特長

* **広告が一切ありません**
* **閲覧できる期間に制限がありません。** 何年先でも何年前でも見られます
* **通信を一切しません。** 潮位は端末内で計算するので、圏外の磯でも使えます
* **Apple Watch 単体で動きます。** iPhone を持っていなくても、機内モードでも潮汐が見られます
* 気象庁の潮位表から推定した調和定数を使用（全国239地点）
* 月をまたいでもグラフが途切れません

### 主な機能

* タイドグラフ（日付・月の境界で途切れない連続表示）
* 長押しで、その時刻の潮位を読み取り
* 満潮・干潮の時刻と潮位
* 「上げ3分」「下げ7分」など潮回りの途中の時刻
* 潮名（大潮・中潮・小潮・長潮・若潮）と旧暦・月齢
* 日の出・日の入り、月の出・月の入り、まづめ時の表示
* 月間カレンダー（潮名と潮差の一覧）
* 通知（満潮・干潮・上げ◯分・下げ◯分／釣行日だけを指定可能）
* ウィジェットと Apple Watch コンプリケーション
* 現在地から最寄りの地点を自動選択

## 使用方法

### 地点を変える

タイドグラフ画面の上部にある地点名（例：東京）をタップすると、地点を選ぶ画面が開きます。「地点」タブからも選べます。よく行く場所は★でお気に入りに登録できます。

Apple Watch では、画面左上のピンのアイコンから地点を選べます。iPhone とペアリングしている場合、地点の選択は自動的に同期されます。

### グラフを操作する

* **横スワイプ**：時間を前後に移動します。何年先でも何年前でも動かせます
* **長押ししてなぞる**：その時刻の日付・時刻・潮位・上げ下げが表示されます
* **12時間〜1ヶ月のボタン**：表示する幅を切り替えます
* **「現在時刻に戻る」**：今の時刻に戻ります

Apple Watch では、**デジタルクラウンを回す**と時刻が進み、その瞬間の推定潮位が読めます。

### 釣行日だけ通知する

1. 「設定」タブで「潮汐を通知」をオンにします
2. 「知らせるタイミング」（時間ちょうど／15分前／30分前／1時間前／2時間前）を選びます
3. 「知らせる潮回り」で、満潮・干潮・上げ◯分・下げ◯分から必要なものを選びます
4. 「通知する日」を「選んだ日のみ」にします（初期設定）
5. カレンダーやタイドグラフ下部の日カードにあるベルのアイコン🔔を押して、釣りに行く日に印を付けます

印を付けた日だけ通知が届きます。すべての日に通知してほしい場合は「通知する日」を「毎日」にしてください。

### 「上げ3分」とは

干潮から満潮までの潮位を10等分して、3割上がった時点のことです。**時間の等分ではありません。** 潮の動きが緩い干潮直後は間隔が広くなります。

## よくある質問

**Q. 圏外でも使えますか？**

はい。潮位はアプリ内で計算しているため、通信は一切必要ありません。機内モードでも動作します。

**Q. Apple Watch だけで使えますか？**

はい。iPhone を持たずに Apple Watch だけでも動作します。ただし初回のインストールには iPhone が必要です。

**Q. 表示される潮位は正確ですか？**

気象庁の潮位表の推算値をほぼ再現しています（全239地点の残差は中央値1.12cm）。ただし**天文潮のみ**の計算で、気圧や風による気象潮（±20〜50cm）は含みません。これは気象庁の潮位表自体も同じです。**航海の用に供するものではありません。**

**Q. 潮名（大潮・中潮など）が他のアプリと違います**

潮名の決め方には複数の方式があり、アプリによって1日ずれることがあります。本アプリは日本で広く使われている慣用表（旧暦日基準）を採用しており、一般的な潮見表と一致することを確認しています。

**Q. 地点を増やしてほしい**

気象庁が潮位表を公開している239地点に対応しています。ご要望はメールでお知らせください。

**Q. 課金すると何か増えますか？**

いいえ。「開発者を応援」は任意の応援で、購入しても機能は変わりません。すべての機能は最初から無料でお使いいただけます。

**プライバシーポリシー**

このプライバシーポリシーは、Takahiro Ito（以下「サービス提供者」）が作成した「まなびのたね」アプリケーション（以下「本アプリ」）に適用されます。本サービスは「現状のまま改変せず」使用することを意図しています。

**収集する情報**

**本アプリは、いかなる個人情報も収集・送信しません。**

本アプリはインターネットに接続しません。すべての機能が通信なしで動作し、外部への問い合わせを一切行いません。したがって、以下のいずれも行っていません。

* 利用状況の外部への送信（アクセス日時、利用時間、操作履歴、学習の成績など）
* 端末情報の収集（IPアドレス、OSバージョン、端末識別子など）
* クラッシュログや分析データの外部送信
* 広告の配信および広告識別子（IDFA）の利用

**アプリ内に保存される情報**

以下の情報は、お客様の端末内にのみ保存されます。外部に送信されることはありません。

* プロフィールのニックネームとアイコン
* 学習の進み具合（文字ごとの習熟度、正解・不正解の回数、もらった星の数）
* 文字ごとの答えの記録（出題された文字、正解かどうか、まちがえたときに選んだ文字、日時）。保護者向けの「学習状況」の表示に使います
* 利用時間の記録（レッスンをしていた時間、レッスンの回数）
* 保護者が設定した1日の利用時間の上限

ニックネームは、保護者の方が任意の文字列を入力するものです。本名を入力する必要はありません。氏名、生年月日、メールアドレス、写真などの入力を求めることはありません。

これらの情報は、保護者エリアからプロフィールごとに削除できます。

**第三者のアクセス**

**本アプリは第三者のサービス（分析、広告、クラッシュレポートなど）を一切利用していません。** 第三者に提供するデータもありません。

**広告・アプリ内課金について**

本アプリには、広告もアプリ内課金もありません。すべての機能を無料でご利用いただけます。

**外部へのリンクについて**

お子様が操作する画面には、アプリの外へ移動するリンクはありません。保護者エリアは、保護者の方による確認（計算問題への回答）を経た場合にのみ開きます。

**お子様のプライバシー**

本アプリは、未就学のお子様を含む幼いお子様が使うことを想定して作られています。本アプリは個人情報を一切収集しないため、13歳未満のお子様を含むすべての方に安全にご利用いただけます。アカウントの登録は不要です。

**オプトアウトの権利**

本アプリは情報を収集していませんが、端末内に保存された情報を削除したい場合は、保護者エリアからプロフィールを削除するか、本アプリをアンインストールしてください。アンインストールすると、保存されていた情報はすべて削除されます。

**このプライバシーポリシーの変更**

このプライバシーポリシーは、理由の如何を問わず随時更新される場合があります。サービス提供者は、新しいプライバシーポリシーでこのページを更新することにより、プライバシーポリシーの変更をお知らせします。変更を定期的に確認することをお勧めします。継続的な使用は、すべての変更の承認とみなされます。

**お客様の同意**

本アプリを使用することにより、お客様は、このプライバシーポリシーに定められた通り、現在および将来の改訂版に従って、お客様の情報の取り扱いに同意したものとみなされます。

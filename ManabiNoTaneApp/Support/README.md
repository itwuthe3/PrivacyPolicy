# まなびのたね サポート

まなびのたねは、時間制限も広告も課金もない、子どもの学習アプリです。ひらがなの読みから始められます。

## よくある質問

### 使いはじめ

**Q. どう使いはじめればいいですか？**
最初の画面の右上にある「おとなのひと」を押し、計算問題に答えて保護者エリアを開きます。「プロフィールを追加」でお子様のニックネームとアイコンを決めると、遊べるようになります。

**Q. アカウント登録は必要ですか？**
不要です。ログイン画面はありません。本名や生年月日の入力もありません。

**Q. きょうだいで使えますか？**
はい。プロフィールは5人まで作れます。進み具合はプロフィールごとに分かれます。

**Q. 文字がまったく読めない子でも使えますか？**
はい。問題や説明はすべて音声で流れます。スピーカーのボタンを押すと、何度でも聞き直せます。

### 学習について

**Q. どんな順番で文字が出てきますか？**
五十音順ではなく、形の単純な字から、1回に2文字ずつ出てきます。「め」と「ぬ」のように形の似た字は、別の回になるようにしています。

**Q. 新しい文字がなかなか出てきません。**
まだあやふやな字が残っている間は、新しい字を出さずに復習を優先します。覚えてくると、次の字が出てきます。

**Q. 覚えた字がまた出てくるのはなぜですか？**
忘れた頃にもう一度出すためです。よくできている字ほど、次に出るまでの間隔が長くなります。

**Q. まちがえたときはどうなりますか？**
ブザーやバツ印は出しません。正しい答えを示して読み上げ、少しあとでもう一度出題します。

### 保護者の方へ

**Q. 遊ぶ時間を制限できますか？**
保護者エリアの「1日の利用時間の上限」で、10分から60分の間で設定できます。初期設定は「なし」です。上限に達すると、その日は新しいレッスンを始められなくなります。途中のレッスンは最後まで続けられます。

**Q. どの字が苦手か分かりますか？**
保護者エリアでプロフィールを選ぶと、文字ごとの進み具合が五十音表の形で見られます。まちがいの多い字と、過去7日の利用時間も確認できます。

**Q. 進み具合を最初からやり直したいです。**
保護者エリアでプロフィールを選び、「進み具合をリセット」を押してください。元に戻せないのでご注意ください。

**Q. 機種変更をしたら、進み具合は引き継がれますか？**
端末のバックアップから復元した場合は引き継がれます。アプリ独自のクラウド保存はありません。

**Q. 広告や課金はありますか？**
ありません。すべての機能を無料でお使いいただけます。

**Q. 子どものデータはどこかに送られますか？**
いいえ。このアプリはインターネットに接続しません。情報はすべて端末の中だけに保存されます。
